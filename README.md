# List Generator (Inferno)

A C++ command-line utility for generating, managing, and processing credential lists, usernames, and passwords.

## Features

- **List Generation**: Create simulated email and username lists with custom domains and passwords.
- **Data Management**: Merge files, remove duplicate entries, count lines, and search specific terms.
- **Export Options**: Convert text files directly into structured CSV format.
- **Safety Features**: Includes path validation, backup creation, and overwrite protection.
